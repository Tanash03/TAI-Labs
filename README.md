# TAI Labs — Workflow Replay

A focused prototype exploring how AI upskilling can be connected to measurable workplace outcomes.

## What it demonstrates

Workflow Replay lets a user capture a real task before and after AI, then calculates:

- Time saved per run
- Monthly hours recovered
- Estimated monthly and annual value
- Quality change
- A concise evidence summary

## Product thesis

**Assess → Learn → Build → Prove → Measure**

The prototype intentionally focuses on the core interaction rather than authentication, integrations, enterprise analytics, or a production AI layer.

## Stack

- Next.js
- React
- TypeScript
- CSS

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Deployment

The app is structured for a straightforward Vercel deployment. No environment variables are required for the current prototype.

## Why Workflow Replay

The core question is not simply whether someone completed AI training, but whether their capability changed the way they work. Workflow Replay makes that change visible as a measurable business outcome.
